# Katikati Rotary Club Website

A redevelopment of the Katikati Rotary Club website using ClubRunner CMS. I redesigned the homepage and members portal, added custom styling, and created a user guide so club members can maintain the content.

## Live Website

Coming soon.

## Technologies

- ClubRunner CMS
- HTML
- CSS
- Git and GitHub

## Features

- Homepage sections for the welcome carousel, featured story, club links, events, and news
- Custom CSS for widget spacing, alignment, and layout
- Members portal with links to the relevant ClubRunner content editors
- Image sizing recommendations for consistent presentation

## Documentation

The [ClubRunner User Guide](./userguide.pdf) explains how to update homepage content, events, and stories. It includes annotated screenshots and guidance for managing images and the stylesheet.
